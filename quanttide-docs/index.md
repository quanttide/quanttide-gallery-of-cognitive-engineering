# 量潮文档工程认知档案

## 定位

文档工程关心文档阅读本身的负担：通过对文档格式做定量分析，以人类阅读体验反向评估内容质量，让 AI 参与写作后依然可读、可维护。

文档工程与叙事工程的分工是：叙事工程关心故事内核与叙事方向，文档工程关心阅读负担等基础指标，两层评估互不替代。「文档格式」章程经论证归属文档工程。

## 结构

文档的连接应该像业务一样有层级：一篇文章内部、一本书内文章之间、一个图书馆内书籍之间（也可跨馆），是三个不同层级的关系，链接应该保持在这个层级之内，而不是随意乱连。链接混乱的根源就是把不同层级的东西混在一起，比如在一个科室内部引用另一个部门的做法却不说明依据。因此文档云要能管理全局结构、预警链接混乱之处，并用关系可视化图支撑治理决策。
