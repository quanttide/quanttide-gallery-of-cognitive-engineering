# 情境

## 治理文档结构

### 感知 L1

腾讯云文档天天跳来跳去，跳了一堆文档最后还不讲正事；自己文档库里的链接也在乱连，AI 参与写作后这种情况更明显。

### 理解 L2

乱链的根源是缺少对链接的显式约定——链接应当基于智能与知识来维护，而不是随意引用；解法分三层：文档保持树状、网状连接仅在业务明确要求时建立；文档云管理全局结构，计算并预警链接混乱之处；关系可视化图不止用于看，还要支撑决策治理。

### 预测 L3

以显式约定维护工作流，文档云就能自动预警混乱之处，人访问时不再出问题；关系图从展示工具变成治理工具，鼓励持续的维护。

## 智能排版文档

### 感知 L1

文档格式（表格、列表、正文）可被解析器解析出具体数字；AI 生成内容格式多且乱。

### 理解 L2

通过对文档格式做定量分析，再用人类阅读体验反向评估，就能得到有效的内容质量指标；文档工程关心的是阅读负担，叙事工程关心的才是讲故事。

### 预测 L3

格式定量指标成熟后，即可用它判断哪些内容需要优化，并与阅读负担检测融合为文档质量的前置过滤，使定量评估成为文档质量的常规评估手段。
