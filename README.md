# quanttide-gallery-of-cognitive-engineering

量潮认知工程画廊 — 从工作日志提炼的认知档案事实源。

## 定位

gallery 是事实源：收录经过人工审核的认知档案，按领域组织，每个领域一个目录，由 index/schema/situation 三个文件构成。

## 领域

- `quanttide-docs/`：文档工程

## 数据流

认知档案的提炼在档案仓库（profile）中进行；gallery 收录已澄清的领域档案。工具消费方（lab）读取 gallery，其推理产物不写回 gallery，gallery 的内容只能通过人工审核修改。
