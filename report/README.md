### 领域描述

#### 认知工程

- **核心关切**：意图工程概念确立
- **认知框架**：将人机辩论理解为意图发现和收敛的具体手段
- **演化方向**：从形式化工具上升到方法论命名
- **关键图式**：
  - 意图工程（debate → contract 收敛机制）
  - 人机协作循环（洞察 → 整合 → 上升）
- **关键意图**：
  - 建立人机协同的反思与辩论模型 [优先级: 高 / 风险: 中 / 触发: 持续]
  - 将意图工程作为认知工程的核心方法论 [优先级: 高 / 风险: 高 / 触发: 持续]

#### 组织管理

- **核心关切**：财务离职后的团队韧性
- **认知框架**：将财务离职理解为一次团队韧性的压力测试
- **演化方向**：从应急响应向制度设计演化
- **核心张力**：法治 vs 人情温度
- **关键图式**：反脆弱转型（人治 → 法治同步演进）
- **关键意图**：
  - 建立反脆弱的团队运作机制 [优先级: 高 / 风险: 中 / 触发: 持续]
  - 实现从人治到法治的文化转型 [优先级: 高 / 风险: 高 / 触发: 持续]

#### 身心健康

- **核心关切**：无意义感与整合感的对冲
- **认知框架**：将心理调节理解为一个"元意图"
- **演化方向**：从被动应对升级为主动认知定位
- **预算信号**：第 3-4 天出现替代性抽离行为
- **关键图式**：元意图保障（恢复成本高，维护频率每日）
- **关键意图**：调节工作节奏与维护心理可持续性 [优先级: 高 / 风险: 中 / 触发: 持续]

#### 基础设施

- **核心关切**：自动化备份与工具链分工
- **认知框架**：将基础设施问题理解为体系化治理问题
- **演化方向**：从具体操作向体系化治理升级
- **关键图式**：体系化治理（被动防守 → 主动设计）
- **关键意图**：
  - 构建安全可靠的平台基础设施 [优先级: 高 / 风险: 低 / 触发: 持续]
  - 理清工具链的归属与分工 [优先级: 低 / 风险: 低 / 触发: 条件]

#### 创新管理

- **核心关切**：POC 范式从操作升格为方法论
- **认知框架**：将研发探索理解为人类提供洞察 + AI 补全整合的协作循环
- **演化方向**：从具体方法向元方法论抽象
- **关键图式**：低门槛验证（验证成本低，复制效率高）
- **关键意图**：
  - 建立以 POC 为核心的快速探索范式 [优先级: 高 / 风险: 低 / 触发: 持续]
  - 利用低耗能模式维持产出 [优先级: 低 / 风险: 低 / 触发: 条件]
